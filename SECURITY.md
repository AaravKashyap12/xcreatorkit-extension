# Reporting a security issue

For a suspected privacy or security issue, contact [Aarav, the maintainer](https://x.com/byaarav), and ask for a private reporting channel before sharing details. Include the extension version, Chrome version, and the affected feature. Reproduce with a test account or fictional data where possible. Keep API keys, cookies, and account exports out of your report.

To understand what the extension can read, see the [privacy policy](https://xcreatorkit.com/privacy.html) and [manifest](static/manifest.json). For ordinary bugs and feature requests, use the [issue tracker](https://github.com/AaravKashyap12/xcreatorkit-extension/issues).
